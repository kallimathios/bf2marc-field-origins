# bf2marc-provenance
Example of which MARC fields come from a BIBFRAME Work or Instance based on the BIBFRAME2MARC 2.10.0 Conversion Spec

This repo includes
* A Library of Congress BIBFRAME Work and Instance for the title Halloluva gamaṭa yamu by Ḍab. Ē. Milṭan Perēra, retrieved on November 5, 2026
* The Stanford University Libraries MARC record for the same title pulled from the FOLIO Production environment on November 5, 2026
* A copy of the Library of Congress bibframe2marc 2.10.0 code in a zip file, retrieved from https://github.com/lcnetdev/bibframe2marc/releases/#release-v2.10.0 on November 5, 2026
* HTML view and analysis vibe coded with Claude Education, Opus 5.5
